# GAIA - Assistente Virtual para a SoulUp

## Descrição do Projeto

O projeto GAIA foi desenvolvido como parte da 1ª Sprint de Front-End Design Engineering da FIAP.
A proposta do projeto é criar uma assistente virtual em formato de avatar para auxiliar os usuários dentro da plataforma SoulUp. A SoulUp já possui seu próprio sistema de missões sustentáveis, portanto a GAIA não cria novas missões.

A função da GAIA é orientar o usuário, explicar funcionalidades, incentivar a participação e oferecer pontos extras quando uma missão já existente na plataforma for concluída. Esses pontos extras podem ser utilizados em uma loja de acessórios para personalizar a própria GAIA, tornando a experiência mais interativa e motivadora.

## Objetivo

O objetivo principal do projeto é melhorar a experiência dos usuários da SoulUp por meio de uma assistente simples, visual e intuitiva.
A GAIA ajuda o usuário a entender melhor a plataforma, acompanhar seu progresso e se sentir mais motivado a continuar participando das ações sustentáveis.
